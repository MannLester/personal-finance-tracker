## 0.1.0 - 2026-11-02

First named V0 source checkpoint, under **Personal Finance Tracker**.

- Offline Android tracking with local SQLite and manual financial inputs.
- Editable income, expense, transfer, contribution, earnings, and adjustment logs.
- Actual, reserved, available, and total-asset balances; savings goals and investment reminders.
- Dark wallet interface, branded zero-balance starter accounts, charts, and display privacy.
- Version-1 JSON backup/restore and data-preserving SQLite migrations.
- Eleven passing automated tests, TypeScript checks, Expo compatibility, clean dependency audit, and successful Android bundle export.
- Public repository, documented version strategy, immutable `v0.1.0` tag, and `version/0` maintenance branch.

This is a source checkpoint, not a new public APK release. Physical-device visual/accessibility checks, Android backup file-picker behavior, and installed-update verification remain outstanding. Earlier `1.0.0` values were template metadata, not a published V1 release. Android's integer version code continues increasing independently.
